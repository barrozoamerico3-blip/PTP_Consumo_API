# Sistema de Consulta Meteorologica em C#

Trabalho Pratico de Consumo de Web API.

## Descricao
Aplicacao desenvolvida em C# que consome a API Open-Meteo para consultar dados meteorologicos de Maputo, Mocambique.

## Funcionalidades
- Consulta de dados atraves de HTTP GET.
- Processamento de respostas JSON.
- Apresentacao da temperatura.
- Consulta da humidade relativa.
- Consulta da velocidade do vento.
- Identificacao das condicoes meteorologicas.
- Tratamento de excecoes.

## Tecnologias
- C#
- .NET 10
- HttpClient
- System.Text.Json
- API Open-Meteo

## Como executar
1. Instalar o .NET 10 SDK.
2. Clonar ou descarregar este repositorio.
3. Abrir o terminal na pasta do projeto.
4. Executar:

dotnet run

## API utilizada
https://open-meteo.com/
